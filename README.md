# 句铭 SentenceInscription · 一句一屏

教材向「逐词拆句」打字练习 + 背单词的网页版。
「把句子拆成词块逐块练」的玩法受 [iwangjie / English-Chunks](https://github.com/iwangjie/English-Chunks) 启发，
代码为独立实现（纯静态 HTML/JS + Python 构建链），在此思路上补教材词库、加背单词与专项练习，改名「句铭」。

- **小学**：湘少版 3–6 年级词表（湖南少年儿童出版社，2022 课标修订版）
- **初一 / 初二 / 初三**：人教版初中英语 7 上 / 7 下 / 8 上 / 8 下 / 9 全册词表
- **所有**：以上全部混合

打字练习的 603 句例句按各级别教材词汇手写，逐词标注音标/词性/中文；
整句朗读用 edge-tts 合成（英音 Sonia），单词发音用词光开源真人英音录音。

## 直接使用

- 双击 `index.html` 即可（数据内置在 `data/*.js`，无需服务器）。
- 或起本地服务：`python -m http.server 5199`，打开 http://localhost:5199

## 玩法一：词块拆句

- **待复习入口**：首页「背单词」下方会出现「↻ 复习待复习 · N 词」（有待复习词才显示）；背单词页顶栏的「待复习 N」也可直接点，进入只复习这批词的模式。
- **双档案（右上角 👦 / 👧）**：男、女两个档案各存各的进度——句子掌握度、背单词记录、最高连击、难度/模式/题量/抽题规则全部独立，点头像即切换，页面就地刷新无需重载。首次运行会把旧版本的进度自动搬进默认档案（男生），数据不丢。
- 一句一屏：英文拆成彩色词块，每块上方是音标、下方是词性和逐词中文，底部是整句中文翻译。
- 难度：所有 / 小学 / 初一 / 初二 / 初三，**除「所有」外可多选**（如小学+初一、初一+初二），选中的年级合池出题；芯片上显示各级句数，选择记忆在 localStorage。「所有」独占，点具体年级则从「所有」切回单选。
- 题量：20 句 / 50 句 / 100 句 / 全部（「全部」= 当前难度整级一次练完）。
- 语法点筛选（抽题规则下方下拉，选择记忆）：按句级语法标签抽题——宾语从句 / 定语从句 / 状语从句 / There be / 祈使句 / 感叹句 / 情态动词 / 比较等级，选项实时显示当前难度下的句数，0 句自动置灰；标签由 `src/grammar_tag.py` 规则打标（已打 828/2806 句），build.py 构建期自动挂载，校对清单见 `data/grammar_tag_review.txt`。默认「全部语法点」不筛选，SRS / 热度抽题逻辑不受影响。
- 抽题规则三种（选择记忆）：
  - **智能 · 错题优先**（默认）：用完提示、看答案、跳过或跳过的句子记为未掌握，下一轮优先再出现；间隔复习用 FSRS 算法（按每句的记忆状态动态安排，掌握越熟间隔越长，上限一年）。错题内部也随机排序，且最近三局的开头句不会重复打头
  - **顺序 · 接着上次**：按教材顺序推进，每轮接着上次的位置继续，练完自动回到开头
  - **纯随机**：每轮独立洗牌，不记录进度
- 开始页会显示当前级别的「已练 / 待复习 / 未练」句数。
- 三种模式：
  - **跟打**：英文可见，照着敲，打对变白
  - **中译英**：英文藏成等长下划线空位（一个字母一段，等宽字体排版、打字不跳动；音标同步隐藏，防止拼写泄露），光标停在空位前面，只看中文自己想
  - **听写**：只播整句朗读，听完默写；词块同样显示为下划线空位
- 打对整句 → `PERFECT`，连击 +1，**停留展示完整答案，按 Enter 或点「下一句 →」再继续**。
- **每句自动朗读**：切到新句子后延时 1 秒自动播整句朗读。
- 卡住时：`💡 提示`（**空格**）逐字揭示并读词（**同一个词只读一次**，连按空格不会反复念同一个词）；`👀 看答案`（Ctrl+Enter）显整句。用过提示的句子不计连击。
- **三种听音粒度互不重叠**：整句朗读=进入句子自动播；点语块=整块连读（听语流/连读/弱读）；空格提示=逐词单独读（听拼写）。点语块不消耗提示、不影响连击。
- **不用管大小写**：全程小写输入即可判对，打对的字符自动按原文大小写显示。

## 查词（背单词第三个模式）

背单词页顶部模式条：**卡片 / 拼写补全 / 查词**。切到查词后输入英文或中文实时过滤
2,577 个词条（英文按 完全相同 > 前缀 > 短语整词命中 排序，water 同时命中 water 和
watermelon；中文按释义包含）；结果带音标 / 词性 / 释义 / 首现单元 / 例句，
**点一条直接打开该词的卡片**（已翻面看释义，自动朗读；该词插进当前队列，
按「下一题」继续原有进度，不打断本轮）。Esc 从查词回卡片，再按才退首页。

## 玩法二：背单词

首页点「📚 背单词」进入，按当前所选难度取词（共 3,270 词条：小学 768 / 初一 921 / 初二 943 / 初三 638，跨级别重复词去重后 2,577；含 Good morning / How are you / What's the matter 等 14 条交际用语整句卡，已过滤人名与无释义的残缺条目）。页内顶部可切两种模式（选择记忆在 localStorage）：

**模式一 · 卡片**

- 卡片正面：单词 + 音标 + 🔊（进卡自动朗读一遍，有真人录音用录音，否则语音合成）
- **空格**（或点卡片）翻面：词性 + 中文释义 + **词形变化**（复数/三单/过去式/过去分词/现在分词/比较级/最高级，
  约 1,500 个词有此行；不可数名词、情态动词、专名自动跳过，生成规则在 `src/wordforms.py`）
  + **例句（全部词条配有例句与中文翻译）**
- 评价只有两档：**1 不认识 / 2 认识**（翻面后再按空格 = 认识）；评价后顶部的「待复习 / 新词」数字实时更新
- HUD 显示该级别待复习 / 新词数量；一轮 20 张，结束给「认识 / 不认识」统计。
- 间隔复习（FSRS 算法，vendor/ts-fsrs.umd.js 离线运行）：认识 → 间隔拉长，不认识 → 当天再见、间隔重算；完全掌握的词最长一年才回来一次。
  队列优先出到期的复习词，不足补新词；进度存 localStorage，次日按到期自动安排。
- **★高频优先**（HUD 右侧开关，默认开）：新词按「语料出现次数 + 题库考点次数 × 2」从高到低排队
  （打分在 `src/freq.py`，只排实义词，the/is 这类虚词沉底）；关闭则回到随机抽词。切换下一轮生效。

**模式二 · 拼写补全**

- 单词随机挖掉部分字母（首字母保留，挖空数按词长 1～5 个、不超过六成），显示词性 + 中文释义，让你补全缺少的字母
- **💡 提示**（输入框旁按钮，或 Ctrl+H / F1）：按顺序揭开下一个空位的字母（金色标出）；用过提示的这题即使拼对也不延长复习间隔，隔一阵还会再考
- 输入框里打的字母实时填进空位（金色光标停在下一个空位），**Enter 检查**：全对绿色 ✓，错了红色标出并给出正确拼写
- **对错直接计入进度**：拼对 = 认识（盒子 +1），拼错 = 不认识（归零、当天必复习），并在该词上累计拼错次数
- 一轮结束统计「拼对 / 拼错」，并列出本轮拼错的词
- 两种模式共用同一份 FSRS 进度，在卡片里 marked 不认识的词，拼写模式里也会优先出现
- 左上角 **←** 随时返回首页；页底有 **重置进度**（点一次变「再点一次确认」，3 秒内再点才清，
  清掉当前档案的 FSRS 进度与拼错次数，不影响打字练习）

## 玩法三：专项练习（三题型）

首页点「✍️ 专项练习」进入，顶部切换三种题型，难度 / 题量 / 抽题规则全部沿用首页设置：

- **语法填空**：对标中考「用括号内单词的正确形式填空」，1,796 题覆盖 21 类考点
- **首字母填空**：同一题库，只给首字母和中文提示（多词答案自动排除）
- **连词成句**：句库语块打乱，鼠标拖拽或点两个交换排序，对标中考连词成句

- 题目区上方是**考点统计条**：总题数 + 每类考点多少题（跟随首页所选难度），
  点某个考点就只练那一类，再点「全部」恢复

- 题目从现有 2,732 句里自动抽取：句中已经有一个正确的变形（went / children / quickly / taller），
  把它挖掉、括号里给原形，答案就是它本身——语境天然正确、答案唯一
- 共 1,778 题，覆盖二十一类考点，其中两类是**无提示填空**（中考语法填空里不给括号的那几个空）：
  冠词（a / an 按后词读音、the 只挖乐器 / 序数词 / 最高级 / the same 这类固定结构）、
  介词（只收 in the morning / listen to / be good at / by bus 等高确定性固定搭配，
  「填别的介词也说得通」的一律不收）；其余十九类是词形变化：
  名词复数、三单、现在进行时（be + doing，副词/主语代词插在中间也能识别）、
  动名词（句首作主语 / like/enjoy 后 / 介词后 / a shopping centre 这类定语）、
  过去式、被动语态（be/get + 过去分词，`be made of/from` 属固定搭配每级最多 3 道）、
  完成时（have/has + 过去分词）、比较级、最高级、形容词变副词（quick→quickly / good→well）、
  be 动词（按主语填 am/is/are/was/were）、代词格（宾格/形容词性物主/名词性物主）、
  名词所有格（father's）、序数词（one→first）、反身代词（enjoy oneself）、
  非谓语（want to do）、构词法派生（-er 表人 / -ful / -y 天气形容词 / -ed-ing 情感形容词 /
  -ness-ment-ity 抽象名词 / un-im- 否定 / -tion）
  （词形引擎在 `src/forms.py`：不规则动词/名词/比较级手工表 + 规则生成，双向校验）
- 考点按学段设门槛：被动/完成时/最高级/反身代词/构词法/形容词变副词只出现在八年级以后、
  非谓语七年级以后，小学不会刷到超前语法
- 一轮题量跟首页「本轮题量」设置一致（20 / 50 / 全部），按考点轮转抽题；
  20 题小于考点数时轮转起点逐轮后移，几轮下来每类都练得到
- 比较级/最高级是唯一需要专门写例句的考点：`more/most + 形容词` 属于多词形态，
  索引里没有这种形式。为此补了 57 句——小学 18 句（六下 Unit 1 的 `A is -er than B`）、
  初二 39 句（一句同时含比较级和最高级，覆盖全部 ≥20 次的高频形容词），
  出题器也单独加了 `more/most + 形容词` 短语扫描，多音节词（important / beautiful）才出得了题
- 难度跟随首页所选学段；一轮 24 题，**错题会加权重新出现**
- 输入框就在句子中间（金色下划线），Enter 检查：对绿色 ✅、错红色 ❌ 并给出正确答案
- **答错有讲评**：不只给答案，还会说清是哪条规则——「一般过去时用动词的过去式；
  以 e 结尾直接加 -d：continue→continued」，答对时也给一句规则，趁热打铁
  （讲评由 `src/tips.py` 按考点 + 形态反推自动生成，全部 1,778 题 0 缺失）
- 卡住时按 **空格** 逐个字母揭示，或点「👀 中文」看整句翻译
- 对错计入 `examprog` 进度（跟随档案），下轮错题优先

## 例句来源（背单词卡片）

| 来源 | 占比 | 说明 |
|---|---|---|
| Tatoeba 日常句 | 59% | 中英对照人工翻译句库（CC BY 2.0），经繁简转换与难度过滤 |
| 教材例句 | 20% | 本项目手写的 603 句拆句练习句 |
| 人工例句 | 10% | `src/pat_examples.json`（245 条）：句型框架、介词短语、文化词 |
| 词光例句 | 6% | 开源词库 AI 例句（只取简单的） |
| 模板生成 | 5% | 只剩专名/人名/月份/节日（"Do you know Bob?"），兜底 100% 覆盖 |

难度约束：句中词落在该学段累计词表内，允许 1–2 个教材后续词（primary 1 / g7-g8 2 / g9 1），
避免 "Please give me a hamburger." 这类好句因一个 give 被整句丢弃。
译文校验：优先选中文里确实含该词释义的句子，避免「kick → 自甘堕落」这类意译。
专名/人名统一标 `name.`（界面显示"专名"），不再套 "This is my Bob." 之类句式。

```

                         · 六下源页面只列 41 词，已按多方词表补齐到 63 词（SUPPLEMENT 表）
                         · 清洗括号注释（father (dad)→father）与 =缩写（can't=cannot→can't）
src/pep-junior-*.json    人教版初中词表（github.com/cyforkk/pep-english-words）
src/corpus/cmn.txt       Tatoeba 中英平行句（manythings.org 抽取版，32,028 对）
src/corpus/tatoeba_api.tsv 按词补抓的 Tatoeba 句（468 对，补教材词缺口）
src/fetch_extra.py       按词抓 Tatoeba：python src/fetch_extra.py dumpling mooncake
src/build_dict.py        合并词典：词光 + 手工功能词表 + 人教版 + 湘少版 → dict.json
src/sentences_*.py       四个难度手写例句（校验：所有词都在对应级别词表内）
src/check_sentences.py   词表校验器（含词形还原）
build.py                 例句数据：分词 → 查词典 → 分块 → sentences.json/js；--tts 生成整句朗读
build_words.py           背单词词库：教材词表 + 词典 + 音频 id → words.json/js
                         · 末尾挂 normalize_defs（释义规范）、wordforms（词形行）、freq（高频分）
src/build_examples.py    背单词例句：教材句 > Tatoeba > 词光 > 模板，并合并回 words.json/js
sync_entries.py          从 word-atlas entries 合并 e2/tip/col（幂等，只填缺失）
src/apply_patch.py       补回重建后缺失的音标/第二例句（src/word_patch.json）
                         + 教研手写的 tip/col（src/word_tips.py，句型框架与核心实义词约 220 条）
src/forms.py             词形变化引擎（不规则动词/名词/比较级表 + 规则生成）
build_forms.py           语法填空出题：从现有例句反向挖变形 → data/forms.js（1,796 题）
```

- 词典优先级：词光 > 手工词条（虚词/专有名词）> 人教版（释义截取前两义）> 湘少版。
- 单词音频：词光 CC BY 4.0 真人英音（按词表全量抽取）；整句朗读 edge-tts（603 条）。
- 点击语块/单词的发音：`python build_audio_extra.py` 生成
  - `audio/c/`：多词语块整块朗读（"in a year."、"any other river"）
  - `audio/w2/`：缺真人录音的词（is/the/to）+ 录音与词形不符的词（teacher→teach、summer→sum、it's→it）
  - 索引 `data/audio_extra.js`（前端按 key 查表，命中就播 mp3，不命中才退回浏览器 TTS）
  - 音色同整句：en-GB-SoniaNeural、rate -5%；断点续跑，已存在的 mp3 跳过
  - 为什么要预生成：浏览器 TTS 依赖系统语音包，中文 Windows 常只有中文音色，读英文直接没声；手机上各机型也不一致
- 例句难度合规：`python src/level_check.py`（可加 `primary|g7|g8|g9` 只看一级）
  - 规则：低年级例句不得出现更高年级才首次出现的单词；高年级可以用低年级的词
  - 判级依据：教材词表（湘少 3-6 / 人教七上~九全）+ 基础功能词表 + 手工补录的小学常用词；词形自动归并（went→go、leaves→leaf/leave、knew→know）
  - 专名（Tom / London / the Palace Museum）、数字（1945 / 25th）、缩写（P.E / A.M / BBC）豁免；句首大写不算专名
  - 多词词条（ice cream / once upon a time / potato chips）按整体判级，动副组合（every day / look up）拆成单词判
- 单词配图：word-atlas 开源插画（CC BY 4.0），`python sync_imgs.py` 从 `../word-atlas/public/atlas/thumb/` 同步到 `img/w/`，名单在 `data/wordimg.js`。
- 深度词条（第二例句/辨析/搭配）：`python sync_entries.py` 从 `../word-atlas/public/atlas/entries/` 合并进 words.json/js（e2/tip/col 字段）。
- 释义规范：`python src/normalize_defs.py`（--write 写回）——同一个词跨册重复收录时，把初中条目的
  词典式释义（I「碘元素；英语字母I」、hello「表示问候；惊奇或唤起注意时的用语」）统一回教材首现义，
  并修正词性与释义错配（deep 标成名词、Miss 标成动词等）；已挂进 `build_words.py` 末尾，重建不丢。
- 背单词数据会过滤人名、无释义与残缺条目（sth./sb./省略号写法），并拼接词组音标。

## 部署（群晖 Web Station / 任意静态托管）

纯静态、零构建：把 `index.html`、`style.css`、`app.js`、`profile.js`、`wordbook.js`、`exam.js`、
`progress.php`、`data/`、`audio/`、`progress/` 放进站点目录即可（`src/`、`build*.py`、`shots/`、`_*.html` 不用上传）。

- **只当静态站用**：不启用 PHP 也能跑，进度存在浏览器 localStorage。换浏览器、换访问地址就各是各的。
- **要落成文件（推荐）**：同目录有 `progress.php` 且站点启用了 PHP 时，每个档案的进度会整体镜像成
  `progress/boy.json`、`progress/girl.json`，打开页面时**以文件为准**：
  - 想清空某个档案的进度 → 直接删掉对应文件，下次打开即为空（空档案不会自动重建，练一句才会再生成）。
  - 需要 Web Station 的运行用户对 `progress/` 有写权限（File Station 里给 `http` 用户组「读写」）。
  - 写入是整文件覆盖，同一档案别在两台设备上同时练；两个档案互不影响。
- 首页不再显示进度落盘提示（这行已去掉）；进度写没写盘看 `progress/` 里有没有对应文件即可。

### 实测部署记录（DSM 7 + 默认服务器，2026-11）

站点形态：Web Station「默认服务器」根目录 = `web` 共享文件夹，监听 80/443，站点就是 `web/chunk`，
访问地址 `http://群晖IP/chunk/`。

1. **PHP 版本**：装 **PHP 8.2** 即可（8.4 下载失败不影响，代码只用到 json/file 基础函数，7.4~8.4 都能跑）。
2. **绑 PHP**：Web Station → 网站 → 编辑「默认服务器」→ HTTP 后端服务器 `Nginx`、PHP 选 `Default Profile (PHP 8.2)`
   → 保存。勾不勾「启用个人网站」无关。
3. **权限**：DSM 的 `web` 共享文件夹常没启用 Windows ACL，File Station 里改不了单个子目录权限。
   最省事的做法是 控制面板 → 共享文件夹 → `web` → 编辑 → 权限 → `http` 组「读取+写入」
   → 勾「应用到这个文件夹、子文件夹及文件」。`progress/` 会自动继承。
   （若只想开最小权限：`sudo chown -R http:http /volume1/web/chunk/progress && sudo chmod 775 /volume1/web/chunk/progress`）
4. **踩坑 502**：绑好 PHP 后访问 `progress.php` 可能返回 **502 Bad Gateway**（Nginx 活着但连不上 PHP-FPM）。
   **重启 Web Station**（套件中心 → 停止 → 启动）即可解决，不需要重装 PHP。
5. 验证命令：`http://群晖IP/chunk/progress.php?p=boy` 返回 `{"ts":0,"data":null}` 即 PHP 正常；
   页面默认进**游客**档案；男生/女生档案要输密码（默认 12345，界面上不提示），
   解锁只在本标签页有效，新开页面又回到游客。

### 避免被 DSM 索引（可选，4000+ 小文件反复扫描会白占 CPU）

先确认有没有被索引：主菜单 → **Universal Search** → 齿轮（偏好设置）→ **文件索引 → 索引文件夹列表**，
在「用户自定义 / Synology Drive / Synology Drive Team Folder」三个标签页里找有没有 `web`。
没有就说明本来没索引，不用处理（`web` 通常不在默认索引范围，默认是 photo / music / video / home）。

DSM 7 的索引任务**只能指定"索引哪些文件夹"，没有"排除子文件夹"的选项**，所以处理方式是"不建任务 / 删掉任务"：

1. **文件索引**：上述列表里选中 `web` → **编辑 → 删除**（或直接删掉该索引任务）。
2. **媒体索引**：控制面板 → **索引服务 → 媒体索引 → 索引文件夹 → 编辑**，把 `web` 移除。
3. **Synology Drive**：若装了 Drive Server，确认 `web` 没有被加成团队文件夹。
4. **Synology Photos**：若 `web` 被设为照片文件夹（共享空间），移除；不用 Photos 可以直接停用套件。
5. **Antivirus Essential**：若启用，把 `web/chunk` 加进排除列表。

顺手降低 I/O（对静态站点有效）：存储管理器 → 存储空间 → **设置 → 记录文件访问时间 → 从不**。

判断有没有服务在扫这个目录：SSH 执行 `ls -d /volume1/web/chunk/@eaDir`，
存在 `@eaDir` 说明有服务（媒体索引 / 缩略图 / SMB）访问过；Web Station 自己不会产生它。

代价：`web/chunk` 里的文件搜不到（不影响网站访问、不影响进度文件读写）。
